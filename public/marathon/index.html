Connexion à GitHub (une fois par PC)

Tes timings sont enregistrés dans ton dépôt GitHub. Pour pouvoir les modifier depuis ce PC, colle un jeton GitHub. Il reste uniquement dans ce navigateur.

  1. Ouvre github.com/settings/personal-access-tokens/new
  2. Repository access : Only select repositories → ton dépôt
  3. Permissions → Repository → Contents : Read and write
  4. Generate token, puis colle-le ici
